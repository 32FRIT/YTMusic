YouTube Data API

غير مُعدّ

يتيح المفتاح البحث عن الأغاني والقوائم العامة وعرضها داخل صفحة التصفح. لا يلزم تسجيل الدخول إلى Google.

أضف مفتاح YouTube Data API للبحث عن الأغاني والقوائم العامة.
أنشئ مشروعًا في Google Cloud، وفعّل YouTube Data API v3، ثم أنشئ مفتاحًا. يُحفظ المفتاح على هذا الجهاز، وتُرسل طلبات البحث إلى Google. لو كان المفتاح مقيّدًا بنطاق، شغّل التطبيق عبر HTTPS أو localhost وأضف النطاق إلى القيود. دليل إعداد YouTube Data API ↗ إدارة مفاتيح Google Cloud ↗
ⓘ

لم تتم إضافة مفتاح بعد. يُحفظ المفتاح محليًا في هذا المتصفح، وتُرسل طلبات البحث مباشرة إلى Google.
